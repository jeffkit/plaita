# 使用指南

本章节带你从零开始使用 plaita：安装、定义流程、写表达式、选择执行模式、处理错误与超时、接入回调、调试流程。

!!! tip "推荐阅读顺序"

    首次使用按顺序阅读 [安装](installation.md) → [快速开始](quickstart.md) → [流程定义](flow-definition.md) → [表达式](expressions.md) → [执行模式](execution-modes.md)。后续按需查阅错误处理、回调与调试。

## 你将学到

- 如何安装 plaita 并验证
- 如何用 JSON 描述一个流程并在本地/远程执行
- 表达式语法如何引用上下文数据与调用函数
- Normal / Generator / Distributed 三种模式的差异与选择
- 节点级/流程级超时、错误策略与重试
- 用回调监控流程生命周期
- 用生成器模式单步调试
